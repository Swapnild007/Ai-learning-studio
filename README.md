# AI Learning Studio

A from-scratch, browser-first AI/ML learning environment with an iOS-inspired interaction model.

## Initial build
- Six connected curriculum modules.
- 520-lesson catalog generated from the curriculum map.
- Lesson reader with prerequisites, mathematics, mechanism, implementation, experiments, failure analysis, mastery evidence and checkpoints.
- Local progress persistence.
- Search, labs, projects and progress surfaces.
- Python local server and static QA test.

## Run
python3 server.py

The next build can deepen individual lesson dossiers, interactive mathematical visualizations, executable notebooks, assessments and project workspaces without changing the shell.
